# 🔐 Phishing URL Detector

A machine learning web application that analyzes URL characteristics and predicts whether a URL may be phishing or legitimate.

## 🚀 Live Demo

Open the deployed web application: **[https://phishing-url-detector-mi7x.onrender.com/]**

## ✨ Features

* Enter a URL for analysis
* Extract URL-based features
* Predict using a trained Random Forest model
* Simple web interface built with Flask
* Deployed online using Render

## 🛠️ Technologies Used

* Python
* Pandas
* Scikit-learn
* Random Forest Classifier
* Flask
* HTML and CSS
* GitHub
* Render

## ⚙️ Run Locally

1. Clone this repository.
2. Install dependencies:
   `pip install -r requirements.txt`
3. Start the application:
   `python app.py`
4. Open `http://127.0.0.1:5000` in your browser.

## ⚠️ Disclaimer

This project is for educational purposes only. Predictions may be incorrect. Do not rely on this tool alone to determine whether a website is safe.
