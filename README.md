# phishing URL Detector
## About the project
This project uses Machine Learning to identify URLs that may be phishing or legitimate. It is built with Python, Flask, and a Random Forest model. 

## Technologies used

- Python
- Flask
- Pandas
- Scikit-learn
- Random Forest Classifier
- HTML and CSS

## Features
- Extracts features from a URL
- Uses a trained Random Forest model
- Predicts whether a URL may be phishing or legitimate
- Provides results through a Flask web interface
